What's next · honest/ 10

Real repos tell you what to build.

Pointing DocGuard at likec4's own API docs surfaced the exact next step — no guessing.

The gap we found

likec4's public API lives in a TS namespace, and its docs describe option-object fields (throwIfInvalid) and CLI flags (--allowed-host) — not raw params. The parser extracted 0 units from LikeC4.ts.

  • Descend into TS namespaces / modules — reach the real exports
  • Extract interface & type-object members as documentable units
  • kebab ↔ camel mapping so --allowed-host links to allowedHost
  • Then likec4's cli.mdx table heals itself, too
Recorded as a tracked follow-up — the tool's honesty is a feature, not an asterisk.
